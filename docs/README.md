## Et les specs ?

Le dossier [`specs/`](../specs/README.md) contient les **spécifications détaillées** et les décisions d'architecture
(ADR). Elles sont précises, mais longues : commencez par ici, et allez dans les specs quand vous avez besoin du détail.
Chaque guide indique la spec correspondante.
